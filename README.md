# PCableTester

Windows desktop utility for Ethernet cable **TDR (Time-Domain Reflectometry)** diagnostics using a local **Realtek PCIe GbE** network adapter.

## Features
- **4-pair TDR cable diagnostics:** detects Open, Short, Impedance mismatch, and Normal pairs with distance in meters.
- **4 test modes:** Open End, Powered Off Device, Powered On Device (live link + TDR lengths), and Loopback.
- **Live continuous mode** with real-time 8-wire visual feedback.
- **Bilingual UI:** Slovak (SK) and English (EN).
- **100% offline:** zero telemetry, zero data collection.

## Requirements
- Windows 10 / 11 (64-bit)
- Realtek PCIe GbE network adapter
- Administrator privileges (required for local Realtek driver TDR IOCTL access)
