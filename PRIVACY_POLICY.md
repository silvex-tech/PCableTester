# Privacy Policy — PCableTester

**Last updated:** 2026-11-24
**Publisher:** Ján Šinkovic
**Contact:** jansinkovic@gmail.com

## English
PCableTester is a local Windows desktop utility for Ethernet cable TDR diagnostics using the local Realtek PCIe GbE network adapter.

- **No personal data collected:** PCableTester does not collect, store, transmit, or share any personal information, telemetry, analytics, crash reports, or usage statistics.
- **100% offline operation:** The application does not connect to any external servers or third-party services. All cable measurements are performed locally on the user's network interface.
- **Local settings only:** Language preference and selected local network adapter index are stored locally in Windows user preferences (`HKCU\Software\JavaSoft\Prefs\sk\cabletester`).
- **Contact:** If you have any questions about this Privacy Policy, contact `jansinkovic@gmail.com`.

## Slovenčina
PCableTester je lokálna Windows aplikácia na TDR diagnostiku ethernetových UTP káblov cez lokálnu sieťovú kartu Realtek PCIe GbE.

- **Žiadny zber osobných údajov:** PCableTester nezbiera, neukladá, neodosiela ani nezdieľa žiadne osobné údaje, telemetriu, analytiku ani štatistiky používania.
- **100 % offline prevádzka:** Aplikácia sa nepripája na žiadne externé servery ani služby tretích strán. Všetky merania prebiehajú výhradne lokálne na sieťovej karte počítača.
- **Iba lokálne nastavenia:** Zvolený jazyk a index sieťovej karty sa ukladajú len lokálne v používateľských nastaveniach Windows (`HKCU\Software\JavaSoft\Prefs\sk\cabletester`).
- **Kontakt:** V prípade otázok kontaktujte `jansinkovic@gmail.com`.
